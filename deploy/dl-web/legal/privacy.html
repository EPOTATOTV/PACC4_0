隐私政策

最近更新：2026-09-24

一、这份政策管什么

本政策适用于 PACC 反作弊客户端（Windows / Linux / Android / iOS / HarmonyOS）、PACC 管控后台，以及下载站 dl.potatotv.asia。它说明我们采集哪些数据、为什么采集、保存多久，以及你可以要求什么。

二、管理后台账号

管理端登录会涉及这些数据：

  • 账号标识（PTEID）、昵称、邮箱或手机号，用于登录、验证码与找回密码
  • 登录审计：时间、来源 IP、客户端 UA、结果（成功 / 失败 / 锁定 / 限流）
  • 安全设置状态：两步验证是否绑定、可信设备记录

密码以不可逆哈希保存，我们自己也无法还原。

三、客户端运行期上报的数据

反作弊要靠运行环境信息才能判断，客户端上报的内容包括：

  • 进程与驱动清单、模块加载记录
  • 硬件与系统指纹摘要，用于识别同一台设备上的异常重复
  • 运行时行为快照：输入时序统计、内存与调用完整性检查结果
  • 对抗性环境信号：调试器、DMA 设备、虚拟化 / 沙箱迹象

我们不上报你的个人文件内容、聊天记录或浏览器历史，也不做屏幕录制。

四、下载站

下载站是静态页面：不写 cookie、不做用户画像、不接第三方统计脚本。

你点击下载时页面会上报一次计数（哪个平台、哪个产物），只用于统计各平台下载量。计数按「天 × 平台 × 产物」聚合保存；服务端会对来源 IP 做当日次数限制以防刷量，该 IP 仅参与这一次限流判断，不写入下载统计表。

五、数据用于什么

  • 判定作弊与风险评分，输出红屏 / 告警结论
  • 账号安全：登录、找回密码、异常登录识别
  • 运维：容量规划、故障排查、下载量趋势

不用于广告投放，也不出售给第三方。

六、保存多久

  • 风险判定与证据留痕：按赛事与运营需要保留，到期删除
  • 登录审计：短期保留，用于安全回溯
  • 下载计数：长期保留，但已是聚合数据，不含个人标识

七、谁会看到

除法律法规要求或司法机关依法调取外，仅向提供服务所必需的人员（管理员、运维）开放，并受权限与审计约束。

八、你的权利

你可以通过 support@potatotv.asia 请求查询、更正或删除与你账号相关的数据。涉及赛事判定证据的部分，需要先完成申诉流程。

九、政策变更

本政策更新后会在本页发布，并同步修改顶部的「最近更新」时间。继续使用即视为接受更新后的版本。

十、联系我们

邮箱：support@potatotv.asia

Privacy Policy

Last updated: 2026-09-24

1. Scope

This policy covers the PACC anti-cheat client (Windows / Linux / Android / iOS / HarmonyOS), the PACC management console, and the download site at dl.potatotv.asia. It explains what we collect, why, how long we keep it, and what you can ask us to do.

2. Console accounts

Signing in to the console involves:

  • Account identifier (PTEID), display name, email or phone number — used for login, verification codes and password recovery
  • Login audit: time, source IP, client user agent, outcome (success / failure / lockout / rate limited)
  • Security state: whether two-factor authentication is bound, trusted-device records

Passwords are stored as irreversible hashes. We cannot recover them either.

3. Data the client reports at runtime

Anti-cheat needs runtime environment signals. The client reports:

  • Process and driver lists, module load records
  • Hardware and system fingerprint digests, used to spot abnormal duplication on the same machine
  • Runtime behaviour snapshots: input timing statistics, memory and call integrity check results
  • Adversarial environment signals: debuggers, DMA devices, virtualisation / sandbox traces

We do not report the contents of your personal files, chat history or browser history, and we do not record your screen.

4. Download site

The download site is a static page: no cookies, no profiling, no third-party analytics scripts.

When you start a download the page reports a single count — which platform, which artefact — used only to measure download volume per platform. Counts are aggregated as "day × platform × artefact". The server applies a per-IP daily limit against abuse; that IP is used for this rate-limit decision only and is not written into the download statistics table.

5. What the data is used for

  • Cheat detection and risk scoring, producing red-screen / alert decisions
  • Account security: login, password recovery, abnormal sign-in detection
  • Operations: capacity planning, troubleshooting, download trends

It is not used for advertising and is not sold to third parties.

6. Retention

  • Risk decisions and evidence: kept as long as the event and operations require, then deleted
  • Login audit: short-term retention for security review
  • Download counts: kept long term, but already aggregated and free of personal identifiers

7. Who can see it

Apart from legal requirements or lawful requests from authorities, access is limited to staff who need it to run the service (administrators, operations), under permission and audit controls.

8. Your rights

Write to support@potatotv.asia to request access to, correction of, or deletion of data tied to your account. Where the data forms part of a tournament decision, the appeal process must be completed first.

9. Changes

Updates to this policy are published on this page, and the "Last updated" date above changes with them. Continued use means you accept the updated version.

10. Contact

Email: support@potatotv.asia
