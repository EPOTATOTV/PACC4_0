快速部署指引

  1. 注册 PTEID 账号：客户端内置注册 / 登录接口，账号体系与游戏账号完全解耦。
  2. 安装客户端：下载对应平台安装包，默认连接 wss://pacc.potatotv.asia/ws/ptv。
  3. 自动接入：客户端登录后建立 TLS 长连接，持续上报本地检测数据。
  4. 云端管控：管理员在 admin.potatotv.asia 查看风险评分、红屏告警与远程查端。

PTV 管控端 API 地址：https://api.potatotv.asia；玩家端长连接地址：wss://pacc.potatotv.asia/ws/ptv。
