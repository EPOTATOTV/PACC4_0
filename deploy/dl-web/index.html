常见问题

FAQ
安装后要一直开着客户端吗？

需要。客户端随系统/平台自启动并常驻后台，检测到外部进程注入会断开本轮对局并上报。手动退出会导致本轮无法被防护。

提示校验和不一致怎么办？

停止安装，重新下载并再次核对。校验和匹配的包才能使用；若持续不一致，可到管控台工单反馈。

iOS 怎么装签名包？

下载后先在系统「设置 → 通用 → VPN 与设备管理」信任对应开发者证书，再打开安装。iPadOS 同理。

会采集我的哪些数据？

只采集判定所需的进程、驱动与运行时快照。账号等敏感数据按审计标准脱敏存储，不做与反作弊无关的采集。

Windows 提示需要管理员权限？

安装驱动层容器必须管理员权限。可先暂时关闭其它签名/调试工具，再以管理员身份重试。

安装前
  • Windows 请先关闭其它签名/调试工具，避免冲突。
  • Android 需开启「安装未知来源」。
  • iOS 为签名安装包，未越狱即可使用。
运行须知
  • 客户端需保持后台运行，随系统/平台启动。
  • 被检测到外部进程注入会断开本轮对局并上报。
遇到问题
  • 先核对设备版本与规格是否满足。
  • 仍异常可到管控台自助门户提交工单。
